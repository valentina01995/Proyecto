


# Restaurante Origen

Sitio web desarrollado para el restaurante Origen, con una presentación moderna y elegante de sus servicios, información principal y medios de contacto.

El proyecto fue creado de manera personalizada utilizando HTML y CSS.
## Tech Stack


- HTML5
- CSS3
- Git
- GitHub
- Vercel
- Google Search Console## Project Structure

Proyecto/
├── index.html
├── Keywords.css
└── README.md
- index.html: contiene la estructura principal del sitio web.
- Keywords.css: contiene los estilos y el diseño de la página.
- README.md: contiene la documentación del proyecto.
## Características desarrolladas a mano
## Featu

- Diseño personalizado para el restaurante Origen.
- Menú de navegación.
- Presentación de la información del restaurante.

- Estilos personalizados mediante CSS.
- Diseño adaptable a diferentes dispositivos.
- Navegación sencilla y organizada.
## Security & Performance 
 Uso del protocolo seguro HTTPS.
- Sitio alojado en Vercel.
- Archivos HTML y CSS optimizados.
- Uso de etiquetas HTML semánticas.
- Control de versiones mediante Git y GitHub.
- Tiempo de procesamiento del build de aproximadamente 1 segundo.
